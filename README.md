# Odin Recipes 

## Description:
Odin Recipes is a project about making a website that contains some dishes, and links to their recipes along with photographs of said dishes.

## By having finished this project We exhibit the ability to:
1. Structure basic HTML webpages.
2. Link webpages together.
3. Add images to webpages by sourcing them from the internet.
4. Use Git to make commits and push them to Github.
